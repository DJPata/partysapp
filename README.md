# Partyabend

Partyspiele als Web-App fürs Handy: Imposter, Drei Würfel, Tic-Tac-Toe, Ich hab noch nie / Wahrheit oder Pflicht.

- **Zusammen spielen:** Raum erstellen, die anderen treten mit dem 4-stelligen Code auf ihrem eigenen Handy bei (Firebase Realtime Database, Zugangsdaten in `config.js`).
- **Auf einem Handy:** alle Spiele auch zum Weitergeben, ohne Internet.
- **Installieren:** Seite im Handy-Browser öffnen, „Zum Home-Bildschirm“ wählen.

Lokal testen ohne Firebase: `?test&pid=a` anhängen (Räume nur innerhalb eines Browsers).
